# LightScheduler — стартовый каркас (boilerplate)

Рабочая заготовка проекта «Smart Scheduled Light Controller» (ESP32): плавный «рассвет» по расписанию **на каждый день недели** от DS3231, показания BME280 в веб-интерфейсе, управление кнопкой (клик по включённому свету — отложить розжиг на N минут; при выключенном свете клик игнорируется; удержание ≥ 2 с — пропустить сегодняшний розжиг) и энергонезависимое хранение настроек в LittleFS.

## Структура

```
LightScheduler/
├── LightScheduler.ino   // setup() + неблокирующий loop(), расписание и состояние кнопки
├── config.h / .cpp      // пины, Config (расписание по дням) + Saver (LittleFS, Atomic)
├── sensors.h / .cpp     // BME280 и DS3231 (+ день недели и ключ даты)
├── light.h / .cpp       // плавный розжиг через LEDC, перцептуальная кривая CURVE_LUT, флаг включения
├── button.h / .cpp      // EncButton: клик и удержание 2 с
└── webui.h / .cpp       // веб-интерфейс настроек (Settings) + WiFi
```

## Установка библиотек (Arduino IDE)

`Sketch → Include Library → Manage Libraries`, установить:

| Библиотека | Назначение |
|---|---|
| **Settings** | веб-интерфейс настроек (класс `SettingsGyver`). ⚠️ В старых материалах называлась **SettingsGyver** — сейчас пакет называется **Settings**. |
| **Saver** | хранение Config в LittleFS (атомарная запись) |
| **EncButton** | обработка кнопки (потребует **GyverIO**, ставится автоматически) |
| **GyverBME280** | драйвер BME280 |
| **GyverDS3231** | драйвер DS3231 (потребует **Stamp**, ставится автоматически) |

Библиотека **Settings** имеет зависимости (GTL, GyverDB, StringUtils, GyverHTTP, BSON, Stamp, Table, StreamIO) — при установке из менеджера библиотек они подтягиваются автоматически.

## Плата

1. `Tools → Board → Boards Manager` → установить **esp32 by Espressif Systems**.
2. Выбрать плату **ESP32 Dev Module**.
3. `Tools → Partition Scheme` → схему с LittleFS/SPIFFS, например **Default 4MB with spiffs** (нужно место под `/config.cfg` и файловый менеджер вебморды).

## Настройка

- **Пины** — в `config.h` (`PIN_PWM_LED`, `PIN_I2C_SDA`, `PIN_I2C_SCL`, `PIN_BUTTON`).
- **Wi-Fi** — в `config.h` (`WIFI_SSID` / `WIFI_PASS`). Если SSID оставить пустым, устройство поднимет точку доступа `LightScheduler` (IP по умолчанию `192.168.4.1`).
- **Часовой пояс** — `TIME_ZONE` в `config.h` (для Москвы `3`).
- **Значения по умолчанию** — поля структуры `Config` в `config.h`: расписание по дням (`days[7]`, 0=Пн…6=Вс, по умолчанию все дни 07:30), `fadeDuration`, `snoozeMinutes`.
- **Кривая розжига** — фиксированная перцептуальная (50 % прогресса → ≈30 % скважности ШИМ); формула, таблица и обоснование — в [`docs/light-curve.md`](../docs/light-curve.md).

## Прошивка и веб-интерфейс

1. Откройте `LightScheduler.ino` в Arduino IDE (все `.h/.cpp` должны лежать в этой же папке).
2. Прошейте плату, откройте Serial Monitor (115200).
3. После подключения к сети откройте в браузере IP-адрес устройства (указан в Serial-мониторе) — появится веб-интерфейс настроек.

## Логика

- **Расписание** — в главном цикле раз в секунду сверяется время DS3231 с расписанием текущего дня (`config.days[weekday-1]`): учитываются общий выключатель `config.enabled`, флаг дня `day.enabled`, час/минута, а также пропуск сегодняшнего дня. При совпадении запускается `light_startFadeIn()`.
- **Розжиг** — LEDC поднимает скважность ШИМ на `PIN_PWM_LED` от 0 до 255 за `config.fadeDuration` по перцептуальной кривой `p^1.73697` (таблица `CURVE_LUT[256]`): 50 % прогресса дают ≈30 % скважности, рантайм — только целочисленный.
- **Кнопка** — клик срабатывает только при включённом свете (`light_isOn()`: идёт розжиг или лента уже горит): гасит свет и откладывает розжиг на `config.snoozeMinutes` минут (неблокирующий таймер). Если свет выключен, клик игнорируется (только лог в Serial); клик в ожидании отложенного розжига тоже ничего не делает — перезапустить/продлить отсчёт кликом нельзя. Удержание ≥ 2 с гасит свет, отменяет отложенный розжиг и пропускает сегодняшний день (на следующий день расписание работает снова). Клик не отменяет сегодняшнее событие расписания: если отложенный розжиг сработал раньше штатного времени, позже сработает и оно. Ручное мгновенное включение — веб-кнопка «Розжечь сейчас».
- **Датчики** — температура/влажность/давление обновляются раз в секунду и отображаются в вебморде (режим без WebSocket, через периодический `onUpdate`).
- **Сохранение** — любое изменение настроек в вебморде пишется прямо в `config`, а Saver в течение ~5–10 с сохраняет структуру в `/config.cfg` (атомарно). Версия формата `'B'`: при обновлении прошивки старый `'A'`-файл игнорируется, настройки один раз сбрасываются на значения по умолчанию.

## Примечание о расхождении с PROJECT.md

PROJECT.md синхронизирован с текущим кодом, включая расписание по дням недели, перцептуальную кривую розжига и поведение кнопки. Единственное историческое уточнение: библиотека в менеджере библиотек называется **Settings** (класс внутри — `SettingsGyver`), а подключение к Wi-Fi выполняется в коде явно — см. `webui.cpp`. Архитектура (Config → Saver → LittleFS, виджеты по указателям) сохранена в неизменном виде.
