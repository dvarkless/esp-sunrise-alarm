# LightScheduler — стартовый каркас (boilerplate)

Рабочая заготовка проекта «Smart Scheduled Light Controller» (ESP32): плавный «рассвет» по расписанию от DS3231, показания BME280 в веб-интерфейсе, ручное управление кнопкой и энергонезависимое хранение настроек в LittleFS.

## Структура

```
LightScheduler/
├── LightScheduler.ino   // setup() + неблокирующий loop(), логика расписания
├── config.h / .cpp      // пины, Config + Saver (LittleFS, Atomic)
├── sensors.h / .cpp     // BME280 и DS3231
├── light.h / .cpp       // плавный розжиг через LEDC (PWM)
├── button.h / .cpp      // EncButton: клик и удержание
└── webui.h / .cpp       // веб-интерфейс настроек (Settings) + WiFi
```

## Установка библиотек (Arduino IDE)

`Sketch → Include Library → Manage Libraries`, установить:

| Библиотека | Назначение |
|---|---|
| **Settings** | веб-интерфейс настроек (класс `SettingsGyver`). ⚠️ В старых материалах называлась **SettingsGyver** — сейчас пакет называется **Settings**. |
| **Saver** | хранение Config в LittleFS (атомарная запись) |
| **EncButton** | обработка кнопки (потребует **GyverIO**, ставится автоматически) |
| **GyverBME280** | драйвер BME280 |
| **GyverDS3231** | драйвер DS3231 (потребует **Stamp**, ставится автоматически) |

Библиотека **Settings** имеет зависимости (GTL, GyverDB, StringUtils, GyverHTTP, BSON, Stamp, Table, StreamIO) — при установке из менеджера библиотек они подтягиваются автоматически.

## Плата

1. `Tools → Board → Boards Manager` → установить **esp32 by Espressif Systems**.
2. Выбрать плату **ESP32 Dev Module**.
3. `Tools → Partition Scheme` → схему с LittleFS/SPIFFS, например **Default 4MB with spiffs** (нужно место под `/config.cfg` и файловый менеджер вебморды).

## Настройка

- **Пины** — в `config.h` (`PIN_PWM_LED`, `PIN_I2C_SDA`, `PIN_I2C_SCL`, `PIN_BUTTON`).
- **Wi-Fi** — в `config.h` (`WIFI_SSID` / `WIFI_PASS`). Если SSID оставить пустым, устройство поднимет точку доступа `LightScheduler` (IP по умолчанию `192.168.4.1`).
- **Часовой пояс** — `TIME_ZONE` в `config.h` (для Москвы `3`).
- **Значения по умолчанию** — поля структуры `Config` в `config.h`.

## Прошивка и веб-интерфейс

1. Откройте `LightScheduler.ino` в Arduino IDE (все `.h/.cpp` должны лежать в этой же папке).
2. Прошейте плату, откройте Serial Monitor (115200).
3. После подключения к сети откройте в браузере IP-адрес устройства (указан в Serial-мониторе) — появится веб-интерфейс настроек.

## Логика

- **Расписание** (час, минута, флаг `enabled`) — в главном цикле раз в секунду сверяется с временем DS3231; при совпадении запускается `light_startFadeIn()`.
- **Розжиг** — LEDC плавно поднимает скважность ШИМ на `PIN_PWM_LED` от 0 до 255 за `config.fadeDuration`.
- **Кнопка** — короткий клик запускает розжиг, удержание отменяет его и сбрасывает флаг срабатывания.
- **Датчики** — температура/влажность/давление обновляются раз в секунду и отображаются в вебморде (режим без WebSocket, через периодический `onUpdate`).
- **Сохранение** — любое изменение настроек в вебморде пишется прямо в `config`, а Saver в течение ~10 с сохраняет структуру в `/config.cfg` (атомарно).

## Примечание о расхождении с PROJECT.md

PROJECT.md описывает библиотеку **SettingsGyver** v2 (в т.ч. автоподнятие точки доступа для настройки Wi-Fi). Текущая библиотека называется **Settings** (класс `SettingsGyver` внутри неё), и подключение к Wi-Fi выполняется в коде явно — см. `webui.cpp`. Архитектура (Config → Saver → LittleFS, виджеты по указателям) сохранена в неизменном виде.
